# CryptoPulse

CryptoPulse is a browser-based cryptocurrency dashboard concept. Its static pages bring together market, portfolio, coin information, learning, and account screens in a single front-end project.

**Live site:** [crptopulse348.netlify.app](https://crptopulse348.netlify.app/)

## Features

- Multi-page cryptocurrency dashboard interface
- Market, portfolio, coin, and learning pages
- Sign-in and account-creation screens
- Responsive layouts and theme controls
- Browser-side demo account state

> CryptoPulse is a front-end demonstration. Account data is stored in the browser; this project does not provide production authentication, execute trades, or connect to a financial account.

## Built With

- HTML
- CSS
- JavaScript

## Run Locally

No package installation or build step is required. Clone the repository and open `index.html` in a browser. For the closest match to the deployed experience, serve the repository root using any static web server.
